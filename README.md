# OSS Contributor Agent

Local-first agentic workflow for discovering, investigating,
implementing, and preparing high-quality open-source contributions.

> **Status:** Concept stage. This repo holds the project brief, and no code has been written yet.

## Why?

Finding a good open-source contribution is often harder than
writing the code.

You need to:

- discover relevant repositories
- find worthwhile issues
- understand unfamiliar codebases
- investigate maintainer expectations
- design an implementation
- make the change
- run project-specific verification
- review the diff
- prepare a quality pull request

OSS Contributor Agent automates the repetitive parts while
keeping the engineer in control of important decisions.
